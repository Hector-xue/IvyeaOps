# ADR-0005 · 许可证选 AGPL-3.0

- **日期**：2026-06-07
- **状态**：已采纳
- **依据**：提交 `license: 改为 AGPL-3.0（智能体会话移植自 AGPL 的 claudecodeui）`

## 背景

准备开源时需要定许可证。项目里的「智能体会话」板块移植自
[claudecodeui](https://github.com/siteboon/claudecodeui)，而它是 AGPL-3.0。

## 决策

整个项目采用 AGPL-3.0。

同时明确：GBrain 是 MIT 且属于**外部集成**（通过命令行调用的独立程序，不是被链接进来的
代码），不影响本项目的 AGPL 认定 —— 这一点写进了致谢章节。

## 理由

- AGPL 的传染性要求：移植了 AGPL 代码，衍生作品必须同样 AGPL，没有选择余地
- 对一个自托管产品来说 AGPL 也是合适的选择：任何人改了拿去做 SaaS，必须把改动放出来
- 与其模糊处理，不如明确标注上游来源并致谢

## 后果

- README 的致谢章节固定标注上游项目及其许可证
- 后续引入任何第三方代码前，都要先确认许可证是否兼容
- 商业化路径受限（这是接受的代价，项目定位本来就是完全免费的自托管工具）
