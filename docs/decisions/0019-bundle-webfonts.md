# ADR-0019 · 界面字体自带字库，直接放 public/fonts

- **日期**：2026-08-21
- **状态**：已采纳
- **依据**：2026-08-21 会话（外观设置的字体族一直是"选了没反应"）

## 背景

外观设置里的字体族选择器有七档，但每一档都只是一串**字体名**：`"Microsoft YaHei"`、
`"PingFang SC"`、`"Source Han Sans SC"`……浏览器按名字去用户本机找，找不到就静默
回落到下一个。

问题是「思源黑体」这一档在**原装 Windows 上一个都装不到**（`Source Han Sans SC` 和
`Noto Sans SC` 都不是系统字体），于是它一路回落到微软雅黑 —— 用户选了它，界面一个
像素都不变。一个点了没反应的开关比没有这个开关更糟。

约束：

- 用户和服务器都在国内，`fonts.googleapis.com` / `fonts.gstatic.com` 不通。挂 CDN
  的结果是白等到超时再回落，比现在还差。
- 本机 `~/.npmrc` 指着腾讯云内网镜像，任何一次 `npm install` 都会把 `package-lock`
  里的 `resolved` 写成外网访问不到的地址（见 [ADR-0008](./0008-lockfile-public-registry.md)）。
- 中文字库很大：Noto Sans SC 可变版全量 17MB。不能让默认用户为一个可选项付这个钱。

## 决策

把字体文件**直接作为静态资源放进 `client/public/fonts/`**，用 `@font-face` 声明，
不走 npm、不走 CDN：

- `inter-latin-var.woff2`（48KB）—— 拉丁可变字重，族名 `"Inter Web"`。
- `noto-sans-sc-gb2312-var.woff2`（2.0MB）—— 思源黑体可变版，用 `pyftsubset` 裁到
  GB2312 的 6763 字，族名 `"Noto Sans SC Web"`。

字体族选项一律写成「拉丁字体 + 中文字体」两段，浏览器按**逐字**回退，两边各用各的
强项。原来那档 `source` 的 id 保留（换 id 会把已经选过它的人重置回默认），栈换成
内置字库。

## 理由

- **为什么自带而不是继续猜本机**：只有自带才能保证"选了就一定是它"。这是这次改动
  唯一要解决的问题。
- **为什么不 npm 装 `@fontsource/*`**：见上面的 lockfile 约束。直接放 woff2 文件，
  lockfile 一个字都不用动，也不给开源用户增加一个安装期依赖。
- **为什么不用 Google 那套 unicode-range 切片**（约 100 个分片/字重，浏览器只下用得
  到的几片）：技术上更优，但要往仓库里塞两百多个二进制文件才能覆盖两档字重。裁一份
  2MB 的单文件是**一个文件、一次下载**，对一个自托管项目更好维护。代价见下。
- **为什么裁到 GB2312 而不是全 GBK**：GB2312 的 6763 字覆盖现代中文约 99.7%，裁完
  2.0MB；扩到全 GBK 的 20902 字是 5.8MB —— 体积翻 2.9 倍，换来的是 0.3% 的字。
- **为什么默认档不动**：`@font-face` 是惰性的，声明在 CSS 里不等于会下载，只有页面上
  真有字要用这个族时浏览器才去取。所以默认「跟随主题」的用户是零成本 —— 这条已经用
  探针验过（`font=theme` 时两个字库都是 `unloaded`）。

## 后果

- 仓库多了 2.1MB 二进制。换来的是三档真正能用的字体，以及不再有"选了没反应"的开关。
- GB2312 之外的生僻字（部分人名用字）由系统中文字体接手。CSS 的回退是**逐字**的，
  所以是"这一个字换了支字体"，不是豆腐块。
- **踩到的坑：Inter 必须用 `unicode-range` 卡在 Latin-1。** Inter 的 latin 子集里
  也有 U+2026（…）和 U+2014（—），而它们在拉丁字体里是"三个小圆点贴基线"。中文的
  省略号写作「……」，用拉丁那支渲染出来就是 `......` —— 对比截图里当场看出来的。
  现在是 `unicode-range:U+0020-007E,U+00A0-00FF`，标点仍旧由后面的中文字体出。
- **服务端要注册 MIME**：`.woff2` 不在本机 stdlib 的 `mimetypes` 表里，`FileResponse`
  会猜成 `text/plain`。浏览器不看 MIME 照样加载字体，但任何按 content-type 做判断的
  代理或安全策略看到的都是假的。已在 `server/app/main.py` 顶部注册，并给 `/fonts/*`
  发一年的 immutable 缓存（文件名自带版本，换字体就换名字）。
- 换字体文件时**必须改文件名**，否则老用户会被 immutable 缓存钉在旧文件上。
