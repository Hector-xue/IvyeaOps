# ADR-0001 · 做成自托管 Web 工作台，而不是桌面软件

- **日期**：2026-04-19
- **状态**：已采纳，至今有效
- **依据**：Hermes 会话，2026-04-19 23:14

## 背景

作者手上是一台没有图形界面的 Linux 服务器，日常通过 SSH 和飞书机器人操作它。想要一个可视化
界面来管理服务器上的 AI 智能体、技能和任务，但原话是：**「首先你要明白一点，在这个服务器上
是打不开可视化页面的」**。

## 决策

在服务器上跑一个 Web 服务，用本地（或手机）浏览器访问它。不做桌面 GUI，不做远程桌面。

## 理由

- 服务器本身没有桌面环境，装一套 X11 只为看界面代价过高
- 浏览器访问天然跨设备：电脑、手机、平板都能用，不需要各做一个客户端
- 后续要接的能力（终端、智能体对话、报告下载）本来就适合 Web

## 后果

- 手机端从第一天起就是一等公民，此后大量 UI 工作都是「手机端也要能用」
- 必须自己解决鉴权问题 —— 一周后加了密码登录，因为「知道 IP 的人都可以访问」
- 界面能力受浏览器限制，真正需要终端体验的地方要靠 xterm.js + PTY 补
- 2026 年 6 月做 Windows 版时，形态依然是「本地起服务 + 浏览器打开」，而不是原生窗口应用；
  Windows 那个控制窗口只是启动器，不是主界面
